## Playback

| Key   | Action            |
| ----- | ----------------- |
| Space | Play/Pause        |
| ⇧←    | Back 5 seconds    |
| ⇧→    | Forward 5 seconds |
| ←     | Previous frame    |
| →     | Next frame        |

The skip amount is 5 seconds by default. Change it in Settings › **General** › **Skip Forward/Back** (1 to 15 seconds). Frame steps pause playback; for audio files a step is 1/30 second.

You can also click the preview to play or pause.

## Working with subtitles

| Key | Action                                    |
| --- | ----------------------------------------- |
| ⌘O  | Open Video or Audio…                      |
| ⌘↩  | Align Subtitles (or Transcribe Subtitles) |
| ⌘Z  | Undo                                      |
| ⇧⌘Z | Redo                                      |
| ⌫   | Delete the selected subtitle              |
| ⌘E  | Export                                    |
| ⌘,  | Settings                                  |

## Arrow keys while editing text

While you're typing subtitle text, the arrow keys move the cursor and select text instead of moving the playhead.

The playback keys also don't work before a file is opened, or while the Export window is open.

Settings › **General** › **Keyboard Shortcuts** lists the playback keys too.
