---
title: Subtitle style
description: Set the font, size, colors, shadow, and position of subtitles; the preview matches the export.
order: 4
---

Click **Subtitle Style** in the toolbar to change how subtitles look. Changes show up in the preview right away, and your settings are remembered for next time.

## Settings

| Setting           | What it does                                                                                                                                                                                                                                                                                          |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Font**          | Opens a searchable list of the fonts installed on your Mac, each shown in its own typeface. **Recently Used** fonts come first, then **Chinese Fonts**, **English Fonts**, and **Other Fonts**. Choosing a font applies it at once and keeps the list open, so you can try several against the video. |
| **Weight**        | Appears only for fonts that come in more than one weight.                                                                                                                                                                                                                                             |
| **Size**          | Text height as a share of the picture height, from 3% to 12%.                                                                                                                                                                                                                                         |
| **Text Color**    | The color of the letters.                                                                                                                                                                                                                                                                             |
| **Outline Color** | The color of the outline around the letters.                                                                                                                                                                                                                                                          |
| **Outline Width** | Outline width as a share of the text size, from 0% to 20%. 0% means no outline.                                                                                                                                                                                                                       |
| **Shadow**        | **None**, **Soft**, or **Strong**.                                                                                                                                                                                                                                                                    |
| **Position**      | Where subtitles sit in the picture: 0% is the bottom, 100% the top. **Bottom**, **Middle**, and **Top** set common positions. The text stays inside the picture at either end.                                                                                                                        |

**Restore Defaults** returns every setting to its original value.

The outline width starts at 0%, so the outline color has no effect until you raise it.

## The preview matches the export

The preview and the exported video draw subtitles the same way. Sizes are all relative to the picture height, so the subtitles look the same at any resolution, including when you export at a lower quality.

The style applies to the video with subtitles only. An SRT subtitle file contains just the text and timing; how it looks depends on the player.
