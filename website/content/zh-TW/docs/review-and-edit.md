對齊後，字幕會出現在預覽下方的編輯器中。選擇一行字幕時，播放位置會移到這一行的開頭。開啟「跟隨播放」可讓正在播放的行保持在畫面中。列表上方會顯示總行數，以及還有幾行待檢查。

## 行的標示

需要留意的行會有一個彩色圓點，背景也會帶有淡淡的同色。把游標移到行上，就會顯示標示的意思。

| 標示     | 名稱     | 意思                                                                                 |
| -------- | -------- | ------------------------------------------------------------------------------------ |
| 沒有圓點 |          | 時間已對上聲音。                                                                     |
| 橘色圓點 | 待檢查   | 時間不確定，建議播放確認。                                                           |
| 紅色圓點 | 找不到   | 聲音中沒有這一行。會顯示「尚未設定時間」，在設定時間前不會出現在預覽中，也不會輸出。 |
| 藍色圓點 | 自動聽寫 | 不在逐字稿中，是從講話辨識出來的，可能有錯字。                                       |

正在播放的行會顯示播放符號，文字變成粗體。

### 標記為已檢查

把游標移到某一行的圓點上，圓點會變成勾號，按下即可標記為已檢查，標示隨之消失。調整某一行的開始或結束時間，也會視為已檢查。

### 逐字稿以外的講話

對齊時如果發現逐字稿沒有涵蓋的講話，列表中對應的位置會出現一列醒目的提示，例如「這裡有 12 秒逐字稿以外的講話」。這一列有：

- 「查看」：跳到這一段並播放。
- 「辨識字幕」：自動辨識這一段並加上字幕，標示為自動聽寫。
- 「×」：這一段不需要字幕時，隱藏提示。

### 提醒

如果整體結果看起來有問題，左側面板會出現提醒，例如大部分字幕在聲音中對不上，或字幕比影片早很多就結束了。

## 編輯字幕

- **文字**：點一下某行的文字直接輸入。
- **時間**：選擇一行。列表下方的「開始」與「結束」各有一個時間欄位（輸入例如 `1:23.45` 後按 Return 鍵）、提前或延後 0.1 秒的按鈕，以及設為目前播放位置的按鈕。「播放這一行」會播放所選的行。
- 「新增」：在所選的行之後插入一行空白字幕；沒有選擇時，插在播放位置。
- 「分割」：在播放位置分割所選字幕；播放位置不在該行內時從中間分割。文字會從中間分開。
- 「與下一行合併」：把所選字幕與下一行合併。
- 「刪除」：刪除所選字幕，也可以按 ⌫ 鍵。
- 「整體平移」：把所有字幕提前或延後。輸入秒數（負數為提前）後按「套用」。

編輯器較窄時，這些按鈕只顯示圖示。

要讓找不到的行有時間，請選擇它並設定「開始」與「結束」。

## 復原

每項修改都能用「編輯」›「還原」（⌘Z）復原，用 ⇧⌘Z 重做。在同一行中連續輸入算一個步驟。在已有字幕時重新對齊，也可以復原。

開啟另一個影片或音檔時，字幕列表會清空重新開始，請先輸出字幕。
