## 播放

| 按鍵   | 動作       |
| ------ | ---------- |
| 空白鍵 | 播放／暫停 |
| ⇧←     | 倒退 5 秒  |
| ⇧→     | 快進 5 秒  |
| ←      | 前一格     |
| →      | 後一格     |

快進與倒退預設為 5 秒，可在設定 ›「一般」›「快進／倒退」中改為 1 到 15 秒。逐格移動時會暫停播放；音檔每一格為 1/30 秒。

也可以按一下預覽畫面來播放或暫停。

## 編輯字幕

| 按鍵 | 動作                   |
| ---- | ---------------------- |
| ⌘O   | 開啟影片或音檔…        |
| ⌘↩   | 對齊字幕（或轉錄字幕） |
| ⌘Z   | 還原                   |
| ⇧⌘Z  | 重做                   |
| ⌫    | 刪除所選字幕           |
| ⌘E   | 輸出                   |
| ⌘,   | 設定                   |

## 編輯文字時的方向鍵

正在輸入字幕文字時，方向鍵用來移動游標與選取文字，不會移動播放位置。

開啟檔案前，或「輸出」視窗開著時，播放快捷鍵也不會作用。

設定 ›「一般」›「快捷鍵」中也列有播放相關的按鍵。
