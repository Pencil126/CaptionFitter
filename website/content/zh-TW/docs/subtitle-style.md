---
title: 字幕樣式
description: 設定字幕的字型、大小、顏色、陰影與高度，預覽畫面即為輸出結果。
order: 4
---

按工具列的「字幕樣式」調整字幕外觀。修改會立即反映在預覽畫面上，下次打開 App 時也會沿用。

## 設定項目

| 設定         | 作用                                                                                                                                                                                                |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「字型」     | 打開 Mac 上已安裝字型的清單，可搜尋，每個字型都以自己的字體顯示。「最近使用」排在最前面，接著是「中文字型」、「英文字型」與「其他字型」。選擇後立即套用，清單會保持開啟，方便對照影片試用多種字型。 |
| 「字重」     | 只有提供多種粗細的字型才會出現。                                                                                                                                                                    |
| 「大小」     | 字體高度占畫面高度的比例，3% 到 12%。                                                                                                                                                               |
| 「文字顏色」 | 文字的顏色。                                                                                                                                                                                        |
| 「描邊顏色」 | 文字外框的顏色。                                                                                                                                                                                    |
| 「描邊粗細」 | 描邊寬度占字體大小的比例，0% 到 20%。0% 為不描邊。                                                                                                                                                  |
| 「陰影」     | 「無」、「柔和」或「明顯」。                                                                                                                                                                        |
| 「高度」     | 字幕在畫面中的高度：0% 貼齊底部，100% 貼齊頂部。「底部」、「中間」、「頂部」可快速設定常用位置。在兩端時文字也會保持在畫面內。                                                                      |

「還原預設值」會把所有設定恢復成原始值。

描邊粗細預設為 0%，所以要調高粗細，描邊顏色才會有作用。

## 預覽即輸出結果

預覽畫面與輸出的影片用同樣的方式繪製字幕。各項尺寸都以畫面高度為基準，所以在任何解析度下看起來都一樣，包括以較低畫質輸出時。

字幕樣式只套用在含字幕的影片。SRT 字幕檔只包含文字與時間，顯示的樣子由播放器決定。
